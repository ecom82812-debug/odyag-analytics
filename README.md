# Аналітика одягу

Дашборд для магазинів одягу moda24, luxsecret і madona. Основа взята з проєкту «конструктори» і адаптована під одяг.

- **Сторінка:** `index.html` (GitHub Pages). Вхід за email і паролем (Supabase Auth).
- **База:** Supabase, проєкт «Odyag Analytics» (`qsaifketkgkkgqsroskp`).
- **Синхронізація:** Edge Function `odyag-sync` забирає замовлення з SalesDrive (tovarka22) кожні 15 хвилин.
- **Архів:** дні до 31.08.2026 перенесено зі старого дашборду без змін. З 01.09.2026 дані рахуються із замовлень CRM.

## Що рахується як у старому дашборді
- Виручка й собівартість підтверджених замовлень, за датою заявки (режим «одразу після підтвердження»).
- **Сума за відмови:** фіксована сума × кількість відмов (105 ₴, змінюється в Налаштуваннях).
- **З/п менеджера:** ставка × замовлення, що стали підтвердженими або відмовою, + % від допродажу по викуплених замовленнях.
  Допродаж за день можна виправити вручну (вкладка «Менеджери»).
- **Частка прибутку магазину** (Вікторія: 20% від прибутку madona) — у вкладці «Зарплата», роль «Частка прибутку магазину».
- **Реклама** вноситься в клітинці таблиці «По днях» (у $ за курсом із налаштувань), **CPO план** фіксується при першому внесенні.
- **Оплати на рахунок** — у клітинці таблиці «По днях». Вони зараховуються в дохід ФОП, обраного у вкладці «ФОП і податки».
- ROAS (ціль ≥ 3x) і ціна ліда (ціль ≤ 4 $).

## Файли
```
index.html                              зібраний дашборд (публікується на GitHub Pages)
dashboard-src/app.js, style.css, demo.js  частини дашборду; збірка: node dashboard-src/build.js && cp dashboard/index.html index.html
supabase/schema.sql                     таблиці, доступ, SQL-функції звітів (ідемпотентний)
supabase/functions/odyag-sync/index.ts  синхронізація з SalesDrive
supabase/cron.sql                       автозапуск кожні 15 хв
supabase/legacy-import.sql              як переносились дані зі старого дашборду
```

## Секрети
У коді й репозиторії секретів немає. Ключ SalesDrive лежить лише в Supabase → Edge Functions → Secrets (`SALESDRIVE_API_KEY`).
